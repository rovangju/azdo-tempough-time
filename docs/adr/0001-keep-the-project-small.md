# 1. Keep the project small

Date: 2026-08-20

## Status

Accepted

## Context

This extension is maintained as a small project. Enterprise-scale process and abstraction would slow development.

## Decision

Prefer direct code, few dependencies, short documents, and one implementation until reuse is clear.

## Consequences

New structure must solve a current need. Future agents should not add process or compatibility layers speculatively.
